A make.fun entry for the [Midnight Fridge Roast bounty](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7): one line roasting a smart fridge that refuses to open after midnight.

## The line

> At 3 a.m. you lock me out like you're protecting the Crown Jewels, not a sad onion and half a lime—open up, you pompous crisper.

## How it works

`main.ts` writes that single line to `/output/entry.txt` using only `node:fs`. Run it with `node main.ts`.
